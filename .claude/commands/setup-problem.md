description: Setup the boilerplate code for a coding problem, with test cases
argument-hint: [file name, problem statement]

# Understand the coding problem
Read the coding problem statement $2 along with any examples if any and understand it. Create a boilet plate python file
with problem summary, unimplemented methods needed for the solution, and test cases that can be run. The user should 
simply be able to try out their solution and use the test cases to test it out. Write it to file ($1) provided in the argument
by the user

# Writing Tests
Write the tests in such a way that all the tests run irrespective of failures in any test case. Tests should print expected 
and got results, and number of tests passed out of total number of tests
